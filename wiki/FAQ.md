# FAQ

**Will it work on my Honda?** Maybe. It has been confirmed on one car; see [Supported vehicles](Supported-Vehicles.md).
Trying it is read-only, and a report either way helps.

**Does it need Windows or Wine?** No. It is a native Linux program, including the GODIAG GD101 driver.

**Can it clear my check-engine light?** Not in the first release. See [Safety](Safety.md).

**Can it tune or reflash my ECU?** No, and that is not a goal. The focus is reliability, diagnosis and keeping a health
history of your car.

**Is it free?** Yes.

**Is the source open?** Not yet: it is private for now and access is given on request.

**Does it send my data anywhere?** Only if you turn on sharing, and then only what you have previewed.
See [Privacy and sharing](Privacy-and-Sharing.md).

**Windows or macOS?** Not tried. Only the Linux build has been run.

**Is this from Honda?** No. It is an independent project.
